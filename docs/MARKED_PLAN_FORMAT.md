# Размеченный формат плана (без LLM)

Если план записан в размеченном формате, FitWeaver разбирает его **детерминированным
парсером**: без LLM, без сети, мгновенно. Повторы (`repeat`, `back_to_offset`, `count`)
вычисляются кодом, поэтому ошибок в структуре не бывает. Свободный текст без маркеров
по-прежнему отправляется в LLM.

Как записать план целиком (обычная запись, размеченный формат, свободный текст) — в
[PLAN_WRITING_GUIDE.md](PLAN_WRITING_GUIDE.md).

Парсер включается автоматически, как только в тексте есть хотя бы одна строка
`**** ШАГ ****`:

- **GUI**, вкладка LLM: вставьте текст и нажмите «Сгенерировать». Статус покажет
  «Разобрано без LLM». Подключать LLM не нужно.
- **CLI**:
  ```bash
  garmin-fit parse-marked plan.txt --output Plan/plan.yaml --profile user_profile.yaml
  ```
  `--profile` нужен только для целей `Пульс: Z1…Z5`, `--year` — для дат без года.
  Обратно: `garmin-fit to-marked Plan/plan.yaml --output plan.txt` — существующий YAML-план в виде
  размеченного текста для правки.
  Без `--output` YAML выводится в stdout. Код возврата 1 означает ошибки в тексте.
- **Plan API** (`POST /v1/generate-draft`): размеченный текст тоже компилируется без LLM.

Полный пример: [`examples/marked_plan_example.txt`](../examples/marked_plan_example.txt).

## Пример

```text
==== ТРЕНИРОВКА ==== 29.09.2026 (вторник) — Интервалы 5×1 км
Общая дистанция: 10 км
Цель тренировки: развитие МПК

**** ШАГ ****
Тип: разминка
Дистанция: 2 км
Пульс: 125–140 уд/мин

**** ШАГ ****
Тип: СБУ
Упражнения: высок. бедро — 2×20 сек; захлёст — 2×20 сек; многоскоки — 2×20 сек

**** ПОВТОР: 5 РАЗ ****
**** ШАГ ****
Тип: работа
Дистанция: 1 км
Темп: 4:05–4:15 мин/км

**** ШАГ ****
Тип: восстановление
Длительность: 2 мин
Примечание: лёгкая трусца
**** КОНЕЦ ПОВТОРА ****

**** ШАГ ****
Тип: заминка
Дистанция: 1.5 км
Пульс: Z2
```

## Тренировка

```text
==== ТРЕНИРОВКА ==== ДД.ММ.ГГГГ (день недели) — Название
==== ТРЕНИРОВКА ==== без даты — Название
```

- День недели необязателен. Его можно писать в скобках или после запятой. Если он не
  совпадает с датой, парсер выдаст предупреждение.
- Если в дате нет года, берётся `--year` или текущий год (с предупреждением).
- Имя файла/тренировки строится как `W{ISO-неделя}_{ММ-ДД}_{Mon..Sun}_{Название латиницей}`.
  Для тренировок без даты используется только название латиницей.
- Строки между заголовком и первым шагом описывают тренировку целиком:
  - `Общая дистанция` попадает в поле `distance_km`;
  - `Общая длительность` попадает в поле `estimated_duration_min`;
  - `Цель тренировки`, `Другое` и прочие строки попадают в описание тренировки.

## Шаг: `**** ШАГ ****`

По одному факту на строку, в виде `Поле: значение`.

| Поле | Значения | Что получается |
|---|---|---|
| `Тип` | разминка, работа, ускорение, восстановление, заминка, СБУ | интенсивность шага (warmup / active / recovery / cooldown), для СБУ — блок `sbu_block` |
| `Дистанция` | `2 км`, `400 м`, `400 метров` | `km` |
| `Длительность` | `30 сек`, `2 мин`, `1 ч 30 мин` | `seconds` |
| `Пульс` | `120–135 уд/мин`, `Z2`, `зона 2`, `до 140` | цель по пульсу; зоны берутся из HR-профиля; `до 140` / `не выше 140` → 60–140 |
| `Темп` | `4:05–4:15 мин/км` или `4:40 мин/км` | цель по темпу; одно значение превращается в диапазон ±10 сек/км |
| `Частота шагов` | `175–185` | цель по каденсу |
| `Упражнения` | `название — 2×20 сек; …` | упражнения СБУ (повторы × длительность) |
| `Интенсивность`, `Примечание` | любой текст | остаётся только в тексте, в YAML не попадает |

Правила:

- У шага может быть **либо** дистанция, **либо** длительность.
- Цель у шага только одна. Если их несколько, используется первая, и выдаётся предупреждение.
- Значения не додумываются:
  - шаг без дистанции и длительности становится шагом «до нажатия кнопки круга»
    (`open_step`);
  - неполная цель (`Пульс: от 130`, одно значение темпа без диапазона — кроме правила ±10 сек)
    отбрасывается; верхний предел пульса (`до 150`) — не неполная цель, он кодируется как 60–150;
  - зона, не настроенная в профиле, игнорируется, если рядом нет явного диапазона.
  
  В каждом таком случае выдаётся предупреждение с номером строки.
- Слова «около», «примерно» и «~» допустимы: значение берётся как точное, с предупреждением.
- Названия упражнений СБУ длиннее 12 символов допустимы, но часы могут их обрезать.

## Повторы

```text
**** ПОВТОР: 4 РАЗ ****
…шаги…
**** КОНЕЦ ПОВТОРА ****
```

- `N` — общее число выполнений группы (4 = выполнить 4 раза).
- Повторы можно вкладывать друг в друга.
- `ПОВТОР: 1 РАЗ` раскрывается в обычные шаги.

## Ошибки и предупреждения

**Ошибки** блокируют создание YAML. Сообщение указывает номер строки. Ошибкой считается:

- незакрытый повтор или `КОНЕЦ ПОВТОРА` без начала;
- повтор без числа;
- неизвестный маркер `****`;
- некорректная дата;
- нечитаемая дистанция или длительность;
- тренировка без шагов;
- шаг до первого заголовка.

**Предупреждения** не блокируют создание YAML. Они показывают, где парсер что-то упростил
или пропустил.

## Код

- `src/garmin_fit/marked_plan.py`: `is_marked_plan()`, `parse_marked_plan()` (дерево шагов),
  `plan_to_yaml_data()`, `compile_marked_text()` (разбор, компиляция и валидация),
  `render_marked_plan()` (дерево обратно в канонический текст).
- `src/garmin_fit/plan_service.py`: `build_plan_draft()` отправляет размеченный текст в
  `build_marked_plan_draft()`, свободный текст — в LLM.
- Инструкция для LLM по тому же формату: `src/garmin_fit/llm/training_text_format.md`.

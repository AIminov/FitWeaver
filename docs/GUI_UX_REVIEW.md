# FitWeaver GUI / UX review baseline

Дата: 2026-07-10

Исходная точка для улучшения desktop GUI и упакованного `FitWeaver.exe`.

## Проверено

- `fitweaver_gui.py`, `packaging/` и PyInstaller spec-файлы;
- `README.md`, `README.ru.md`, `TODO.md`, `CLAUDE.md`, `AGENTS.md` и `docs/`;
- `python -m unittest discover -q`: 309 тестов, `OK`.

## Фактическая структура

GUI содержит четыре вкладки: `Календарь`, `LLM Генератор`, `Конструктор`,
`Garmin Connect`. Слева находятся профиль, параметры Garmin и команды, справа
постоянно видна изменяемая по ширине панель вывода. Есть простой/экспертный
режим. Упакованный Windows-вариант поставляется парой
`FitWeaver.exe` + `garmin-fit-cli.exe` в одной папке.

## Подтверждённые проблемы

### Высокий приоритет

1. Нет единого busy-state: `_run()` запускает новый subprocess на каждый клик,
   а генерация, проверка LLM и Garmin-операции работают в отдельных потоках.
   Нужны защита от конфликтующих действий, статус и отмена где возможно.
2. В конструкторе некорректный числовой ввод проглатывается через
   `except ValueError: pass`; пользователь видит старое значение без ошибки.
3. Долгая генерация показывает только статический текст «Генерирую YAML…» и не
   имеет отмены.

### Средний приоритет

4. YAML-путь не показывает состояние файла, валидность или несохранённые
   изменения.
5. После одиночного удаления в Garmin Connect список и итоговая сводка могут
   оставаться устаревшими.
6. `_gui_draft_HHMMSS.yaml` может столкнуться при двух сохранениях в секунду и
   не очищается автоматически.
7. Simple mode всё ещё показывает технические поля профиля, периода и
   dry-run; основной путь должен быть визуально главным.
8. README-файлы отставали от GUI: не были перечислены `Конструктор`,
   simple/expert и требование пары exe.

## Приоритет работ

1. Надёжность операций и обратная связь.
2. Безопасное редактирование существующих тренировок в конструкторе.
3. Более сфокусированный Simple mode.
4. Улучшение календаря и Garmin Connect.
5. Косметическая полировка темы и размеров.

## Критерии готовности

- конфликтующее действие нельзя запустить повторно;
- ошибка видна у действия и в общем логе;
- после изменения YAML/профиля календарь и путь синхронизированы;
- есть backend-тест и ручной smoke-тест GUI/exe;
- README, README.ru, TODO, CLAUDE и AGENTS отражают фактическое поведение.
